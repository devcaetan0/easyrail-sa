🚂 Organização do Repositório do Projeto: EasyRail

  • 📄index.php O coração e ponto de entrada da aplicação. É a primeira página carregada quando o sistema é acessado no servidor.
  • 📖README.md A vitrine do projeto para o GitHub. Contém toda a documentação, instruções de instalação, tecnologias utilizadas e as famosas badges.
  • ⚖️LICENSE Define as permissões legais de uso do software, garantindo a proteção e os termos de distribuição do nosso código.
  • 📁assets/ Onde mora a identidade visual do projeto. Guarda todos os arquivos estáticos como CSS, imagens e ícones.
    • 🎨css/style.cssA folha de estilo global que define cores, espaçamentos e toda a beleza da nossa interface.
  • 📁components/ A nossa fábrica de peças reutilizáveis. Tudo que se repete nas telas (como menus e cards) é modularizado aqui.
    • 🧩cards, clima, navbar...Pedaços de interface (UI) que importamos nas páginas principais para evitar repetição de código.
    • 📁landing-page/Os blocos estruturais que compõem especificamente a nossa página inicial de apresentação.
      • 📄developers.php, footer.php...
    • 📁modals/Aquelas janelinhas pop-up interativas que abrem na tela sem recarregar a página toda.
      • 📁add/Formulários embutidos para cadastrar novos itens (frotas, rotas, sensores).
      • 📁edit/Formulários já preenchidos que aparecem quando clicamos para atualizar algum dado.
  • 📁config/ O núcleo de conexões e integrações de bibliotecas externas que sustentam o funcionamento do app.
    • 🔌conexao.phpO cabo de rede do projeto: o script PDO seguro que liga nosso PHP ao banco de dados MySQL.
    • 📦bootstrap.html / links.htmlOnde declaramos rapidamente as CDNs do Bootstrap e outras dependências globais.
  • 📁database/ O cofre de dados do projeto. Contém as plantas arquitetônicas do nosso banco relacional.
    • 🗄️db.sqlO script com todas as tabelas (CREATE TABLE) e relacionamentos para iniciar o banco do zero.
  • 📁docs/ & pesquisas/ A nossa base de conhecimento técnico e de gestão. Anotações valiosas sobre o desenvolvimento.
    • 📚manual-usuario.mdO guia passo a passo ensinando o cliente final a utilizar e navegar pelo sistema EasyRail.
    • 🔬apis, crud, scrum.md...Nossos estudos de viabilidade, anotações sobre a metodologia Ágil (Scrum) e relatórios de IA.
  • 📁public/ O "Front-end" em PHP. São as telas principais que o usuário final e os gestores realmente acessam e interagem.
    • 🏠home.phpO painel de controle (Dashboard) principal logo após o usuário fazer o login com sucesso.
    • 🔐login.phpA porta de entrada segura do sistema. A tela de autenticação para usuários cadastrados.
    • 🚂frota, rotas, sensores.php...As páginas completas onde visualizamos, em formato de tabela e listas, os dados do sistema.
  • 📁scripts/ A vida da interface. Arquivos JavaScript que dão movimento, validação e dinamismo às telas, sem precisar recarregar o PHP.
    • ⚡api-CEP.js / api-clima.jsComunicações em segundo plano (AJAX/Fetch) que buscam dados em tempo real na internet.
    • 📜frota.js, rotas.js...Responsáveis por controlar os cliques, paginação e preparar os dados antes de enviá-los ao banco.
  • 📁source/ O motor do sistema ("Back-end"). Onde acontecem as regras de negócio, validações ocultas e a verdadeira manipulação do banco.
    • 🛡️auth-login.phpO segurança do sistema: script que checa se o e-mail e a senha existem no banco e cria a sessão.
    • 📁create/Processa os dados que vêm dos formulários (POST) e faz o comando INSERT no banco.
      • ⚙️frota-create, rota-create...
    • 📁update/Recebe as edições do usuário e atualiza (UPDATE) as informações antigas no banco de dados.
      • ⚙️frota-update, rota-update...
    • 📁delete/A lixeira do sistema. Executa com segurança o comando DELETE para remover registros indesejados.
      • ⚙️frota-delete, rota-delete...
